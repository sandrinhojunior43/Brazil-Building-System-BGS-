Política de Privacidade

⚠️ Modelo genérico — revise com um advogado para adequação à LGPD (Lei 13.709/2018) antes de publicar.

1. Dados coletados

Coletamos e-mail e senha (via Supabase Auth) para autenticação, e dados de uso do app (treinos concluídos) para os recursos de progresso. Dados de pagamento são processados diretamente pelo Stripe — não armazenamos número de cartão em nossos servidores.

2. Uso dos dados

Os dados são usados exclusivamente para operar o app: autenticar seu acesso, liberar conteúdo premium e mostrar seu histórico de treinos.

3. Compartilhamento

Compartilhamos dados apenas com os provedores necessários para operar o serviço: Supabase (autenticação/banco de dados) e Stripe (pagamentos).

4. Seus direitos

Você pode solicitar a exclusão da sua conta e dados a qualquer momento, entrando em contato pelo e-mail abaixo.
